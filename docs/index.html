Run on Linux

Read-only CLI

Collect an actual report

On a Linux machine you own or administer, run the following command from the cloned repository. Python 3.11+ required.

python3 -m opspulse --out-dir reports

Open reports/report.json using the report picker above. This is a point-in-time snapshot, not live monitoring.

Interpret with care

  • CPU load is not CPU utilisation.
  • Disk capacity is not drive SMART health.
  • Service state is not end-to-end availability.
  • Backups remain unverified without a restore test.
  • DNS and TCP probes are opt-in in the Linux collector.
