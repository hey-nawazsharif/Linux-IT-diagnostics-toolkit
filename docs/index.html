How to interpret this report

  • Local Linux checks are read-only. DNS, TCP and systemd service checks run only when requested.
  • Disk capacity is not a SMART drive-health test; service status does not establish end-to-end application health.
  • A successful report does not prove backups are recoverable. Conduct a separate restore test.
  • No passwords, environment variables, IP addresses, MAC addresses or username/hostname inventory are collected.
