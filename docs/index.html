Use real Linux measurements

On a Linux machine you own or are authorised to administer, download this repository and run the read-only Python collector with Python 3.11+.

python3 -m opspulse --out-dir reports

Open the generated reports/report.json above to review that point-in-time report. Importing a file does not make this website a remote monitor.

Interpret results responsibly

  • Disk capacity is not drive SMART health.
  • Service status is not an end-to-end availability test.
  • Backups stay not verified without a separate restore test.
  • DNS and TCP probes are opt-in when running the Linux collector.
  • This browser demo requires no account, external scripts, API keys or paid service.

GitHub Pages serves static files; it cannot read your device's CPU, memory or network interfaces.
